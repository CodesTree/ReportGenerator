# Word Generation

Produce a professionally formatted, editable quarterly magazine in `.docx`, the
sole required publishing format. No Canva integration. Human approval is required
before final publication. Template, document library, issue length, and detailed
layout validation are later-phase decisions; no generator is implemented.

[[memory/concepts/editorial-engine]] supplies readable articles and balance
requirements. [[memory/concepts/claim-verification]] supplies traceable references.
