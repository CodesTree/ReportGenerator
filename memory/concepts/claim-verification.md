# Claim Verification

Every material factual claim must trace to a valid DOI or URL. Link resolution
alone is not proof. Independently check against primary evidence where possible;
disputed or high-impact claims need stronger corroboration. Unsupported claims
must never appear as verified facts. Retain metadata and verification status.

[[memory/concepts/research-pipeline]] supplies sources;
[[memory/concepts/editorial-engine]] depends on verified evidence and accurately
expressed uncertainty. [[memory/concepts/word-generation]] must preserve usable
references in the final document. Materiality and verification rubrics remain
open; no verification service is implemented.
